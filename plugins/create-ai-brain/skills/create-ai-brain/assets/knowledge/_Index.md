# Knowledge Index

A compact manifest of every note in `Knowledge/` — title, one-line summary, tags. This exists so linking new notes to old ones doesn't require opening every file in the folder: read this one file, shortlist candidates by tag/topic overlap, then only open the actual shortlisted notes to confirm and link.

Maintained incrementally by the nightly consolidation prompt (see "Knowledge linking" in `System/Nightly Consolidation Prompt.md`) — a new row gets appended whenever a new Knowledge note is processed. Don't rebuild this from scratch; don't edit by hand unless fixing an error.
