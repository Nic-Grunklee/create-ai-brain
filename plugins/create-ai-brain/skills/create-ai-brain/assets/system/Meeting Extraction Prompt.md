# Meeting Extraction Prompt

Use this right after any meeting. Paste your raw notes or transcript along with this prompt.

```
Extract from this meeting:
1. DECISIONS. What was decided, by whom, why.
2. COMMITMENTS. Who promised what, by when.
3. PREFERENCES. How people want to work and communicate.
4. KEY INSIGHTS. Frameworks, strategic shifts, non-obvious observations.
Output as markdown. Skip small talk.
```

## How to use it

1. Drop the meeting transcript or raw notes into your Inbox (or paste directly into chat).
2. Run this prompt against it.
3. Save the output as a note — link people, projects, and companies mentioned so they connect into your vault's web of notes.
